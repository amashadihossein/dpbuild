# dpbuild

The goal of `dpbuild` is to streamline the process of building a data
product.

## Installation

For released version

``` r
remotes::install_github("amashadihossein/dpbuild")
```

For dev version

``` r
remotes::install_github("amashadihossein/dpbuild", ref = "dev")
```
