# Purge Local Pins Cache

It completely deletes content of local cache. Use with care!

## Usage

``` r
purge_local_cache(path_cache = pins::board_cache_path())
```

## Arguments

- path_cache:

  path to pins cache. Default is
  [`pins::board_cache_path()`](https://pins.rstudio.com/reference/board_cache_path.html)
