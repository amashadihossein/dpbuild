# Get input metadata from dpinput manifest

Build the last dpinput from `.daap/daap_input.yaml`

## Usage

``` r
dpinput_map0(project_path = ".")
```

## Arguments

- project_path:

  current project path

## Value

input_map0 a data.frame that maps the content of the already synced
input content or NULL if no `.daap/daap_input.yaml`
