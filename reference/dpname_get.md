# Get Data Product Name

A helper function that build data product name (i.e. what the pin is
going to be called)

## Usage

``` r
dpname_get(data_object)
```

## Arguments

- data_object:

  Data Object. It anticipates project_name and branch_name to be
  attributes of this data object

## Value

dp_name a character that will be tagged back as attribute to data_object
