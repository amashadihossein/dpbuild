# flatten the read dpinput in the format of dp_map

recursively traverses list out of `dir_process` and flattens the list of
read data capturing the structure as path name

## Usage

``` r
dpinput_flatten(read_dpinput0)
```

## Arguments

- read_dpinput0:

  out of call to `dir_process`

## Value

a one level deep list of data tables with name of each element capture
the folder structure info
